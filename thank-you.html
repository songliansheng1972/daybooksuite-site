Thank you for your interest in Daybook Suite.

Everything is currently free — no account, no payment. Get the code below and run it.

1. Get the code

Two ways — they give you exactly the same thing:

Clone the repository (recommended)

Always the latest, always auditable. No dependencies — copy it anywhere and run it.

git clone https://github.com/songliansheng1972/daybook-suite.git

Browse or download a zip

Repo: github.com/songliansheng1972/daybook-suite
Tagged release: Releases → v4.0.5

Straight talk: the source is open (MIT / AGPL-3.0) and free for anyone to fetch. There is no paid product right now. A paid one-click bundle may come later — not now.

2. What you may do with it

  • daybook and daybook-mcp — MIT. Use them freely under the MIT terms.
  • daybook-orch — AGPL-3.0-or-later for open-source use.
  • Commercial use of daybook-orch (closed-source embedding, hosted SaaS without open-sourcing) needs a separate commercial license — write to hi@daybooksuite.com.

3. Getting updates

Watch or star the repository to be notified of new tags. Nothing phones home — no telemetry, no license check, no activation, no email signup.

4. If something is wrong

There is no paid product, so there is nothing to refund — see the Refund Policy. If something does not work, email hi@daybooksuite.com and we will take a look.
