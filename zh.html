你的记忆是纯文本，不是黑箱。

别人都在往上叠 — 向量库、记忆框架、又一个「第二大脑」App — 而 Daybook 套装选择退到底层、回归本体： 纯文本、append-only、零依赖。 记忆不该是黑箱，它该是一叠你翻得动的账页。

它是什么

Daybook 套装是三件各自独立的小工具，共用同一底座、同一份真相：

daybook — 账与录（起居注）

本地纯文本的日志与索引。Append-only。没有数据库、没有服务器、不被锁定。MIT。

daybook-mcp — 查（璇玑）

把你的 daybook 挂载到任何支持 MCP 的客户端。只读取向、可挂载、不绑定模型。MIT。

daybook-orch — 令（司南）

跨智能体与任务的编排与调度。AGPL-3.0-or-later，或商业许可。

为什么是纯文本 — 八件要紧的事

  • 纯文本 — 东西是你的。用 cat 就能读，记事本打开即看，随处归档、比对、备份。不是二进制，不是私有格式 — 人机均可读。
  • 零依赖。只用 Python 3 标准库；不联网。拷到任何机器即跑（Windows / macOS / Linux / 树莓派 / 随身硬盘）。
  • 只增不改。一条一记，append-only；没有隐藏状态、没有遥测、不绕云端。写不坏历史，每条必带作者 ID，可审可验可追。
  • 快。36.5 万条全量索引约 3.7 秒；100 万条追一条 0.28 秒，且不随总量增长。
  • 多写者安全。O_APPEND 原子追加；20 进程同写一卷零交错，1000 并发测试零失误。
  • 图是引用，不是嵌入。图丢了，文本不烂。
  • 可挂载为智能体的长期记忆。能 cat 就能读，30 秒上岗。
  • 跨年代。Python 3 + sh + C + Fortran + BASIC（1957–2026）— 记忆比工具活得久。
