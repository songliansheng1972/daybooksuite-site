Your memory as plain text, not a black box.

While everyone stacks more layers on top — vector stores, memory frameworks, another “second brain” app — Daybook Suite steps back down to the substrate: plain text, append-only, zero dependencies. Memory should not be a black box. It should be a stack of ledger pages you can actually read.

What it is

Daybook Suite is three small, independent tools that share one foundation and one source of truth:

daybook — the ledger (起居注)

A local, plain-text journal and index. Append-only. No database, no server, no lock-in. MIT.

daybook-mcp — the query face (璇玑)

Exposes your daybook to any MCP-capable client. Read-oriented, mountable, model-agnostic. MIT.

daybook-orch — the conductor (司南)

Orchestration and scheduling across agents and tasks. AGPL-3.0-or-later or a commercial license.

Why plain text — eight things that matter

  • Plain text — you own it. Read it with cat, open it in Notepad, archive, diff, back it up anywhere. Not binary, not a private format — human- and machine-readable.
  • Zero dependencies. Python 3 standard library only; never phones home. Copy it to any machine — Windows, macOS, Linux, a Raspberry Pi, a USB drive — and it runs.
  • Append-only. One entry at a time, never rewritten; no hidden state, no telemetry, no cloud round-trip. History stays history — every entry carries an author ID, auditable and verifiable.
  • Fast. 365,000 entries index in ~3.7s; appending one to a million takes 0.28s — and does not grow with the total.
  • Multi-writer safe. O_APPEND atomic appends; 20 processes writing one volume with zero interleaving; a 1,000-concurrent test with zero errors.
  • Links are references, not embeddings. Lose the graph and the text is still intact.
  • Mountable as an agent's long-term memory. If you can cat it, it can read it — onboarded in 30 seconds.
  • Cross-era. Python 3 + sh + C + Fortran + BASIC (1957–2026) — memory that outlives the tools.

Scale

7,735 lines of dependency-free Python across the three packages (daybook 1,992 · daybook-mcp 3,548 · daybook-orch 2,195) — plus thin ports in shell, C, BASIC, and Fortran. Current version v3.2.3.
